# PR Body Template

Fill from the verified patch and assessment. Most sections: one or two bullets.
Omit **Prior proposal** unless reproposing after an `unknown` (or similar
non-suppressing) closure.

```markdown
## Improvement
- What changed and why.

## Safety
- Intended behavior and why correctness is preserved or improved.
- Why this is one coherent improvement.

## Verification
- Checks run and useful tests added or changed.

## Grug
- Applicable principles and how the change satisfies them.

## Prior proposal
- Previous closed PR and why reproposal is justified.
```
